# 问道 1.63 服务端与管理台

一份 Docker Compose 启动 MySQL、1.63 一线游戏服和 Web 管理台。首次启动自动导入空服种子，创建数据库用户、后台管理员和运行卷。提供与管理台目录匹配的 1.63 运行基线。GitHub Release 同时提供可选的 Windows 1.63 客户端分卷。

## 启动

安装 Docker Engine 或 Docker Desktop，使用 Linux 容器。解压后在本目录运行：

```sh
docker compose up -d --build
docker compose ps
```

首次构建需要访问 Docker 镜像仓库和软件包仓库。游戏首次加载可能要几分钟，等 `game` 显示 `healthy` 再打开游戏客户端。

| 用途 | 本机地址 |
| --- | --- |
| Web 管理台 | http://127.0.0.1:18888 |
| 游戏登录 | 127.0.0.1:18101 |
| 游戏一线 | 127.0.0.1:18160 |

用下面的命令查看这次安装自动生成的后台登录信息。在「账号与元宝」里注册普通游戏账号，再用匹配的 1.63 客户端登录建角色。

```sh
docker compose run --rm --no-deps setup admin
```

## 让其他电脑连接

同一台电脑上游玩时，默认值即可。局域网部署时，在目录下新建 `.env`，将下例 IP 换成运行 Docker 的电脑地址。

```dotenv
SERVER_PUBLIC_IP=192.168.1.20
GAME_BIND_IP=0.0.0.0
```

`SERVER_PUBLIC_IP` 是客户端实际能连到的 IPv4 地址。`GAME_BIND_IP` 是宿主机监听地址。需要远程访问后台时，可以用 SSH 端口转发，或自行配置带访问控制的 HTTPS 入口。MySQL 在 Compose 内部网络中运行。

端口冲突时可选设 `GM_PORT`、`LOGIN_PORT`、`GAME_PORT`，客户端需使用对应的游戏端口。

## 假人管理

游戏一线就绪后，在后台「假人管理」按地图和等级设置金、木、水、火、土人数。首次启动名单为空。每个等级组可独立选择经典或新版角色形象，以及装备、宠物和标道。保存后由服务端生成玩家型假人。

天墉城的空闲假人会在擂台下方、门派返城点旁站街。游戏内可邀请组队、快速组队或切磋，带队后假人和宠物会参加战斗。高级宠物按等级从多个品种抽取，70 级及以上的假人会随机决定是否乘骑。后台在场名单支持角色名、等级、门派筛选及分页，并显示出战、掠阵宠物和角色形象。

战斗中，假人会参考队长已提交的攻击目标，机制限制阶段使用符合限制的动作。体木按技能和目标情况施放群毒或群疗，敏水优先补防。假人和出战宠物可用高级血玲珑救人，同一目标每回合只安排一次用药，优先让快的救慢的。BOSS 结算后，假人留在原队。

从旧版升级时，在原安装目录更新压缩包里的文件，然后执行 `docker compose up -d --build`。原 Compose 项目和命名卷用于保留已有数据。

## 保存与分享

`docker compose stop` 停服，`docker compose up -d` 恢复。账号、角色、配置及密码都保存在当前 Compose 项目的命名卷里。`docker compose down -v` 会删除这些数据，仅用于明确要清空的隔离安装。

发布种子只包含空表结构、开服所需的系统路由和空公告键。分享原始压缩包即可，接收方首次启动会得到自己的后台密码和数据库凭据。分享内含的游戏运行材料前，请确认有相应的分发权限。

## Windows 客户端

把同一 Release 的全部 `wendao163-windows.7z.*` 放在同一目录，用 7-Zip 打开 `.001`。将解出的 `wendao163-windows` 与此目录放在同一父目录，双击客户端的 `Start-Client.cmd`。

- Docker 和客户端在同一台 Windows 上，默认连接 `127.0.0.1:18101`。修改过服务端 `.env` 时，启动器会读取相邻组合版的 `SERVER_PUBLIC_IP` 与 `LOGIN_PORT`。
- Docker 在另一台电脑上，按上面的局域网方式配置。再把客户端的 `server.env.example` 另存为 `server.env`，填入运行 Docker 的电脑 IPv4 和登录端口。Windows 还需要能访问服务端公布的一线端口。
- 新账号在后台「账号与元宝」创建。保持 Windows 游戏窗口正常登录流程。

## 角色管理

选中角色后可在同一个页面查看属性、已有宠物、任务、日常重置、好友亲密度和物品发放。「任务管理」的大飞支持补齐前置，已有元婴或血婴的角色沿用原形态。

如果沿用已经初始化过的旧版数据库卷，启动后执行一次下面的命令，给后台补装大飞所用的数据库过程。新安装在首次启动时会自动安装。

```sh
docker compose exec mysql bash /entry/install-full-flight.sh
```
